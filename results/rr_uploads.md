# 历代上传 agent 本地循环赛（2026-09-24）

| 项目 | 内容 |
|---|---|
| 参赛 | 队伍 26 次成功上传里的 23 份不同代码（重复上传只算一次）。submissions 里有 5 个；另外 18 个用 `kg.py fetch` 从 Kaggle 下载到 data/uploads/，大小全部核对无误 |
| 局数 | 6740 局，没有出错或超时的 |
| 公开级别 7 个 | 两两各 100 局：seed 9000 到 9049，每个 seed 两边座位各打一次 |
| Frank 自写 16 个 | 凡涉及它们的每对 20 局：seed 9000 到 9009，两边座位各一次 |
| 得分率 | (胜 + 0.5 × 平) / 局数，对每个对手等权平均 |
| 引擎 | 本地 fastarena（kaggle-environments 1.32.7），原始数据 results/rr_uploads.jsonl |
| 实盘冻结分 | 各提交被挤掉时冻结的分数，冻结时间不同，不能直接互比 |

## 结论

- 胜率最高的是 cha22 加改动（56529338，正在跑）：对另外 6 个的得分率 90.2%，对 cha22 原版 97 胜 3 负。
- 现在在跑的两个提交正好是本地第一和第二。
- 除了对 cha22 原版，加改动版和原版的胜负几乎一样（只对 morewheat 多赢 2 局），平均每局多赚 22 到 35；改动的优势主要体现在打原版副本上。
- Frank 自写的 16 个版本对 7 个公开级别 agent 一共 2240 局全负。它们之间 v19 最强，大体上版本越新越强。

## 复现

```
.venv\Scripts\python.exe tools\rr.py --seeds 50 --seed0 9000 --workers 14 --both --resume --out results/rr_uploads.jsonl --agents <7 个公开级别的 main.py>
.venv\Scripts\python.exe tools\rr.py --seeds 10 --seed0 9000 --workers 14 --both --resume --out results/rr_uploads.jsonl --agents <上面 7 个加 Frank 的 16 个>
```
