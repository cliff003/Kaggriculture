# 擂台赛（整晚自动运行）

## 怎么运作

| 部分 | 说明 |
|---|---|
| 擂主 | 起点是线上 v6（gold/arena/champ0/main.py，就是 submission.tar.gz 里的 main.py，sha256 a8a2e5a1） |
| 挑战者队列 | gold/arena/queue/*.txt，第一行是 agent 文件路径，第二行是说明；按文件名排序依次上场 |
| 每场比赛 | 挑战者对擂主，32 个种子双座位共 64 局，用 DSM 实盘 92 个世界的真实商店序列，每场换一批新种子 |
| 换擂主（第一关） | 64 局正面得分率（胜 1、平 0.5）达到 60% 直接过；52% 到 60% 加赛到 128 局，达到 56% 才过（02:25 前是 55% 和 53%） |
| 换擂主（第二关，02:40 起） | 过了第一关的挑战者再打大体检：6 个固定对手（cha22、emu_eager、morewheat、rescue、v15stack、herdsafe_race）各 32 局。胜场不能比线上 v6 少 4 场以上，平均差不能比 v6 低 600 以上（02:30 起；02:40 前后短暂用过 250），否则记为"正面赢但体检不过"，不换擂主 |
| 进化搜索 | gold/arena/search.py：队列少于 3 个时，在当前擂主配置上随机改 1 到 2 个开关，生成 4 个新挑战者 |
| 可变的开关 | v6 层：抢卖区间和起止时间、卖单排序容差、后期抢跑、开局小麦、卖单优先起始步；cha22 层：抢跑深度、提前卖的价格门槛、带货时刻、抢跑窗口；额外层：肥料提前卖、小麦提前卖、贵货提前卖、小麦做市、盯对手收获、最后一天清仓 |

## 怎么停

- 新建文件 gold/arena/STOP：擂台打完当前这场后退出。
- 新建文件 gold/arena/STOP_SEARCH：进化搜索在一分钟内退出。

## 注意

- 擂台只看和擂主的正面交手，赢了说明在同族镜像对局里更强；实盘七成对手是 cha22 同族，这正是有用的方向，但最终擂主还要对更大的面板和实盘录像重放再核一遍才能考虑提交。
- 所有挑战者都在 gold/ 下，没有改动 submissions/、research/cands/。
- 不会自动提交，提交前会按规矩列出文件、sha256、说明和会被挤掉的旧提交，等你说"提交"。
