# Figures

The seven figures in `docs/img/` are generated by the code in this folder. Each one is an HTML page with inline SVG, rendered by headless Chrome at device scale 2 (3200 px wide), in a light and a dark variant. The README and the docs embed both with `<picture>`, so GitHub shows the one that matches the reader's theme.

```bash
python docs/figures/build.py                 # all figures, both themes
python docs/figures/build.py --only 03 04    # some figures
python docs/figures/build.py --data          # first rebuild data/ (needs the local replays, see below)
```

Requirements: Python 3.12 with Pillow, and Chrome (or Edge) installed. The fonts are vendored in `fonts/` and embedded into each page, so the output does not depend on system fonts.

## Files

| File | Role |
|---|---|
| `frame.py` | design tokens (light and dark), fonts, the slide frame (header band, caption bar, section bars, cards, chips) and the pass-1 check script |
| `svg.py`, `icons.py` | scales, lines, arrows, brackets; 24 × 24 line icons |
| `fig01_agent.py` to `fig07_production_gap.py` | one module per figure: title, subtitle, caption, alt text and `body(theme, data)` |
| `build.py` | renders every figure, runs the checks and writes `docs/img/NN_stem_{light,dark}.png` |
| `data/` | the numbers behind the figures as tables (`facts.json`, `final_board.csv`, `labels.csv`, `winrate_bands.csv`, `standing.csv`, `uploads.csv`, `lineage.json`, `milk_race.json`, `turn_example.json`, `wheat_rounds.json`) |
| `data_build.py`, `rounds.py` | rebuild `data/` from the final leaderboard, the episode lists and the recorded games (not in this repository); every derived number is asserted against the value quoted in the docs |

`rounds.py` re-runs a recorded game in `kaggle-environments` 1.32.7 with the market instrumented, so Figure 03 shows the real fills of four wheat rounds unit by unit (the live game reproduces the server's final money exactly).

## Checks

`build.py` stops on any failed check:

- **Layout:** the page height, fonts loaded, no text overflowing its box, nothing outside the canvas, no colliding labels (pass 1, from the rendered DOM).
- **Numbers:** every number visible in a figure must appear in `data/` or in the figure's own short list of axis values and derived numbers.
- **Dashes:** no en dash, em dash or minus sign (U+2013, U+2014, U+2212) in the figures or in any Markdown page of the write-up.
- **Size:** each PNG is exactly 3200 px wide and twice the page height.

## Colour

One hue per layer family on the mechanism figures (selling blue, fixes and production aqua, wheat arbitrage orange, counter-arbitrage violet; rivals and the public base grey) and per approach on the data figures (learned blue, production aqua, market orange). Team 42 is an ink dot with a yellow halo. Text is always ink or grey, never a series colour.

Palette check (categorical, adjacent pairs, colour-vision simulation and contrast against the surface):

| Mode | Palette | Result |
|---|---|---|
| light, surface `#fcfcfb` | `#2a78d6`, `#1baf7a`, `#eb6834`, `#6250d6` | lightness, chroma, CVD separation (worst ΔE 9.2), normal-vision floor (worst ΔE 24.0): pass; contrast: aqua 2.74:1 is below 3:1, so every aqua mark carries a direct label |
| dark, surface `#1a1a19` | `#3987e5`, `#199e70`, `#d95926`, `#9085e9` | all checks pass (worst CVD ΔE 9.4, normal-vision ΔE 20.9, every hue at least 3:1) |
